# StorySplitter AI - Overview

> StorySplitter AI is a client-side web utility engineered for AI filmmakers, visual artists, storyboard directors, and concept designers. It automatically detects, crops, organizes, and batch-exports panels from multi-frame storyboard sheets generated by Midjourney, Stable Diffusion, DALL-E 3, Flux, or hand sketches.

## What Problem Does StorySplitter AI Solve?

Generative AI models produce multi-panel storyboard grids on single canvas images. For downstream video generation (Runway Gen-3, Luma Dream Machine, Pika Labs, Kling AI, Hailuo), every panel must be extracted as an individual, clean image frame with exact aspect ratios (e.g. 16:9 widescreen or 9:16 vertical shorts).

Manually slicing 20 to 100 panels in image editing software like Photoshop or GIMP takes hours and breaks creative momentum. StorySplitter AI automates this process within seconds, running entirely in the browser.

## Core Pillars

1. **Zero-Server Processing (100% Client-Side Privacy)**:
   Images, projects, and metadata are processed purely inside the client's browser using HTML5 Canvas, Web APIs, and IndexedDB. No files, pixels, or storyboard concepts are ever uploaded to an external server. The tool functions completely offline.

2. **Adaptive AI Edge Detection**:
   A built-in computer vision engine scans sheet contrast, detects panel boundaries, ignores whitespace and outer margins, and isolates individual shots. A k-NN adaptive learner suggests optimal detection parameters based on previous confirmations.

3. **Multi-Page Sequence Management**:
   Directors can upload dozens of sheets at once. An interactive page drawer provides immediate switching, thumbnail previews, per-page custom frame layouts, and synchronized exports.

4. **Aspect Ratio Enforcement**:
   Lock frames to cinematic 16:9, vertical 9:16, 1:1 square, 4:3, or freeform mode. Adjusting frame sizes preserves exact proportions to avoid stretching or letterboxing in video tools.

5. **Session Bundles (.storysplitter)**:
   Users can save their work into portable `.storysplitter` project archives, containing high-resolution image data, crop coordinates, panel labels, and history for seamless session resumption.
